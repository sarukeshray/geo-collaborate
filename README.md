GeoCollaborate
An AI-powered platform for crowdsourcing and analyzing urban infrastructure issues, built for a 24-hour national-level hackathon with the theme "Open Innovation".

✨ Features
Real-time AI Analysis: Users can upload an image of a pothole, and a custom-trained YOLOv8 model will detect and count the instances in real-time.

Interactive Map: All submitted reports are displayed on a live Leaflet map, providing a geolocated overview of infrastructure issues.

Data-Driven Dashboard: A live dashboard shows key statistics, such as the total number of reports and total potholes detected by the AI.

Heatmap Visualization: Instantly toggle from individual markers to a heatmap view to identify problem hotspots and density.

Open API Backend: A high-performance backend built with Python and FastAPI, ready to serve data to municipalities, private companies, and researchers.

🛠️ Tech Stack
Frontend: React, Leaflet.js, Axios, Chart.js

Backend: Python, FastAPI, SQLAlchemy

AI / Machine Learning: PyTorch, YOLOv8, Google Colab for training

Database: SQLite
